# List all packages in metapip

List all packages in metapip

## Usage

``` r
metapip_packages(include_self = TRUE)
```

## Arguments

- include_self:

  Include metapip in the list?

## Examples

``` r
metapip_packages()
#>  [1] "cli"        "glue"       "gh"         "httr2"      "data.table"
#>  [6] "rstudioapi" "remotes"    "gitcreds"   "collapse"   "rlang"     
#> [11] "colorDF"    "metapip"   
```
