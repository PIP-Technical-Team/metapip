# Install branch from a package

Install branch from a package

## Usage

``` r
install_branch(package = "pipapi", branch = NULL)
```

## Arguments

- package:

  one of the core package name (default "pipapi")

- branch:

  valid branch name (default "PROD")

## Examples

``` r
if (FALSE) { # \dontrun{
  install_branch()
  install_branch("pipfun", "ongoing")
} # }
```
