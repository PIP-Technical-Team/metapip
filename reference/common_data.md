# Pivot common branches to wide format (internal)

Pivot common branches to wide format (internal)

## Usage

``` r
common_data(complete_data)
```

## Arguments

- complete_data:

  \`data.frame\` from \[get_complete_data()\].

## Value

Wide \`data.frame\` with one row per package and columns for \`PROD\`,
\`DEV_v2\`, \`QA\` branch versions.
